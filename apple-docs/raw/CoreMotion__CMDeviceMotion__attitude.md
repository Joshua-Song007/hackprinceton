# attitude

The attitude of the device.

```
var attitude: CMAttitude { get }
```

## Discussion

A [`CMAttitude`](/documentation/CoreMotion/CMAttitude) object represents a measurement of attitude—that is, the orientation of a body relative to a given frame of reference.
