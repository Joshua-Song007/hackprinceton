# ModeToggle

Chooses where input comes from: **Simulator** or **Live devices**. It sits at the right of the toolbar, like Xcode's run destination, and switches in one click with no confirmation, because game code never changes between the two. Choosing Live fills the segment with `live` and tints the toolbar edge and status bar (see StatusBar), the same idea as Unity's Play Mode tint, so nobody forgets real hardware is driving the scene. The labels are words, not icons. Shortcut ⌘⇧L.
