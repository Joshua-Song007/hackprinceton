# Button

Push buttons follow macOS: 24px tall, sentence-case verbs ("Calibrate", "Record 10 s", "Add Virtual Watch"). One **default** button (accent fill) per sheet or dialog, for the action that completes it; panels usually have none. Toolbar actions such as Run and Stop are **borderless icon** buttons with a tooltip and a shortcut. Disable a button only when the reason is visible nearby; otherwise let it run and report the problem.
