# Vector3Field

Edits a position, rotation or scale. A label line (name left, unit right), then three number fields whose X, Y and Z letters carry the axis colors, as in Unreal's transform fields; the color is the only place axis hue appears in panels. Drag a letter to scrub (Shift for fine steps, as in Figma and Blender), type to set, double-click the letter to zero. The label sits on its own line above the fields with the unit at its right, so values never truncate in a 240–280px panel. World up is +Y. Provide the value, the unit and a step.
