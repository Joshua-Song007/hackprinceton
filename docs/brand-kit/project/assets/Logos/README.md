# Logos

- `omni-gizmo-light.svg`: the mark for light grounds. A coordinate gizmo: Y up in light `axis-y` (#2e7d22), X in `axis-x` (#c22f2a), Z in `axis-z` (#1f63c4), origin in `text` (#1d1d1f).
- `omni-gizmo-dark.svg`: the same mark for dark grounds, using the dark-theme axis colors and a #e4e5e7 origin.
- Minimum size 16px. Clear space: one stroke width on every side. Don't recolor the axes, rotate the mark, or place it on `accent` or `live` fills.
- Lockup: the mark, then "Omni" in the system font at 600 weight, mark height 1.3 × cap height, gap 0.4 × mark height.
- macOS app icon: the dark mark centered on a `viewport` squircle at 60% width; build it in Icon Composer from the SVG.
