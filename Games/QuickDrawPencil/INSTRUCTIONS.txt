Quick Draw Pencil Squeeze (separate game)
Import Games/QuickDrawPencil/pear-game.json using Studio's game-folder import, then publish as a NEW game (do not overwrite Quick Draw). All scene, UI and scripts are local to this folder.
Run Live Preview for that game. Choose Companion motion bridge for the iPhone (phone-role) slot, even though the assigned Companion is an iPad with Pencil Pro. Join a second physical browser player with role=phone in the same game/lobby; the default iPad preview slot is a referee, not an opponent. Run the existing local relay (cd Web/studio && npm run relay), connect Companion on the same Wi-Fi, connect Studio to the relay, opt into motion and Pencil Pro squeeze forwarding, and assign the Companion device to that slot. Ready both players using the existing UI. Enable Squeeze in iPad Settings > Apple Pencil.
Squeeze Apple Pencil Pro after DRAW to draw the gun; squeezing during arming is an early-draw foul. This is not painting, tip contact, double-tap, or browser pointer input. Existing motion and button controls remain available. Squeeze is momentary and does not need a subsequent phone-lower event. Timing uses server arrival time, including relay/network latency.
The browser-only hosted player does NOT capture native squeeze. Studio and the Companion relay must remain running. A companion sequence restart requires reopening Live Preview and fresh player sessions. Hardware squeeze and remote publishing have not been verified by these automated tests.
